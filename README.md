# MedicAlgo

Website for MedicAlgo — algorithm, data, and AI services for medical device and biotech companies, with a focus on electrophysiology.

Live site: [medicalgo-ai.com](https://medicalgo-ai.com)

## Structure

```
.
├── index.html        # Main page (single-page site)
├── css/style.css     # Styles
├── js/main.js        # Carousel, fade-in, navigation
├── images/           # Site images
└── CNAME             # Custom domain config for GitHub Pages
```

## Local preview

Open `index.html` in a browser, or serve with any static server:

```
python -m http.server 8000
```
